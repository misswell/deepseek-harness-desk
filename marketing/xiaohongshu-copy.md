## 正文

最近自己折腾了个小项目，分享给同样用 Mac、又不想碰命令行的小伙伴——**DeepSeek Harness Desk**。
它就是一个很简单的 SwiftUI 桌面客户端，负责把官方的 DeepSeek Harness Web UI 装进一个原生窗口里跑起来。能力有限，做得比较粗糙，还在慢慢改。

几个我觉得还算实用的点：

🔧 **不用装 Node.js，也不用敲命令**
第一次启动会自动下载装好运行时，全程有界面提示，对不太熟终端的人会友好一点。

🖥️ **窗口尽量简洁**
去掉了标题栏和工具栏，网页顶到屏幕边缘，看起来会清爽一些。

🍔 **菜单栏有个小图标**
关掉窗口也不会退出，点图标随时回来；设置里可以隐藏 Dock 图标。

🛡️ **尽量不给你添麻烦**
自动选端口、启动健康检查、崩溃了试着恢复；就算强杀 App，下次打开也会自己清理残留进程。

🔄 **更新做得比较谨慎**
App 和内置 dsh 分开更新，带校验，装坏了会自动回滚，不至于把应用弄"废"。

💙 **开源、免费**
第三方独立项目，代码都在 GitHub 上，做得不好也欢迎提 issue，大家一起完善。

适用人群大概是：Mac（macOS 14+）用户、喜欢 DeepSeek、又不想折腾环境的人。

目前版本 v0.2.26，GitHub 可直接下载，有 Apple 签名和公证，装起来比较放心。

要是觉得有用可以评论区聊聊，人多了我再写个安装说明～ 说得不对的地方也请多包涵。
